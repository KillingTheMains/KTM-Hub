Read this before you patch. Patch Plot is a planning aid, not the show file. Footprints are the manufacturer's published channel counts for each mode and change with firmware — the Encore Performance went from 33 to 38 channels, the Scenius Unico from 39 to 40. Confirm the fixture's own menu before you address it.
What the numbers assume. One universe is one DMX line is one node port, and a universe never spans two positions. Every fixture is counted as one unit load; ANSI E1.11 §5.10 allows 32 per line, Pathway plans on 30, and the 24 default is touring practice for RDM discovery speed, not a standard. Fixtures never straddle a universe boundary, so a full universe is rarely 512 used channels. Run limits: ESTA's recommended practice keeps a DMX line under 300 m (1000 ft) and RDM gets flaky well before that; Cat5e/6 is 100 m (328 ft) by TIA-568, past which you are on fiber. Termination (120 Ω) is assumed on every line and is mandatory for RDM.
Addressing. sACN (E1.31) universes are 1–63999 on UDP 5568, multicast 239.255.hi.lo, default priority 100. Art-Net 4 port addresses are 15-bit and zero-based — Net 0–127, Sub-Net 0–15, Universe 0–15 — so sACN universe 1 is Art-Net 0.0.0. Wireless receivers (CRMX, W-DMX, Multiverse) start a fresh line with the same 32-load budget; they are noted per fixture but not planned here.
